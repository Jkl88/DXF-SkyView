# DXF SkyView

Просмотрщик DXF-файлов на Python (PySide6 + ezdxf).

## Запуск

```bash
pip install -r requirements.txt
python main.py
```

Открыть файл сразу:

```bash
python main.py путь\к\файлу.dxf
```

## Возможности

- Корректное отображение линий, дуг, окружностей, полилиний и блоков (INSERT)
- Панель свойств выбранного объекта внизу окна
- Подсветка выбранных элементов (Ctrl — множественный выбор)
- Инструмент «Измерить» с привязками и подписями размеров
- Единицы измерения из DXF ($INSUNITS)
- CAD-привязки: конечная точка, середина, центр, квадрант, пересечение, перпендикуляр, касательная, ближайшая, узел
- Меню привязок с вкл/откл
- Удаление выбранных объектов (Del)
- Светлая/тёмная тема по системным настройкам

## Управление

| Действие | Клавиша/мышь |
|----------|----------------|
| Открыть файл | Ctrl+O |
| Вписать в окно | F |
| Панорама | Средняя кнопка мыши |
| Масштаб | Колёсико мыши |
| Выбор | ЛКМ |
| Множественный выбор | Ctrl + ЛКМ |
| Удалить | Del |
